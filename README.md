# Pharmacy & Medicine Reminder Management System — Frontend

Responsive React + Vite frontend demo with a login page and patient dashboard.

## Run in VS Code

1. Extract this ZIP file.
2. Open the extracted `Pharmacy_Medicine_Reminder_Frontend` folder in VS Code (the folder containing `package.json`).
3. Open Terminal → New Terminal.
4. Install dependencies:
   - PowerShell: `npm.cmd install`
   - Command Prompt: `npm install`
5. Start the app:
   - PowerShell: `npm.cmd run dev`
   - Command Prompt: `npm run dev`
6. Open the local URL printed by Vite, usually `http://localhost:5173`.

## Demo login

Enter any valid email address and any non-empty password to open the sample dashboard. The sign-in state is stored only in the current browser session. Use the Log out option in the sidebar to return to the login page.

## Included screens

- Login page
- Overview dashboard
- My Medicines (add, search, remove)
- Reminders (mark a dose as taken)
- Prescriptions
- Appointments
- Orders

## Important limitations

This is a frontend demo only. It does not include a backend, MongoDB, real user authentication, password storage, password reset, email verification, real medicine orders, or device notifications. Do not enter a real or reused password. A production login requires a secure backend and password hashing.
